# Buckley Belts — brand palette

Source: theme CSS variables on https://www.buckleybelts.nl/ (pulled 2026-09-23). Tokens live in `buckley-palette.css`.

The site is dark-mode first: near-black surfaces, white type, and one warm cream accent for CTAs.

| Role | Token | Hex |
|---|---|---|
| Page / header / cards | `--bk-ink` | `#0E0E0E` |
| Footer, overlays | `--bk-black` | `#000000` |
| Supporting dark | `--bk-graphite` | `#252627` |
| Text | `--bk-white` | `#FFFFFF` |
| **Accent / primary CTA** | `--bk-cream` | `#FCF2D3` |
| Sale badge | `--bk-gold-light` | `#FFEBAD` |
| Review stars | `--bk-gold-star` | `#F5E1AD` |
| Hero gradient | `--bk-gradient-hero` | `#3C4144 → #171D21` |
| Success / warning / error | — | `#609D6E` / `#FF7B00` / `#F83A3A` |

Typography: **Lato** throughout (400 body, 700 headings).
